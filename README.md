# Resonance MIDI Player

「ブループロトコル：スターレゾナンス」の楽器演奏向けに、Standard MIDI File（MIDI）の音符をWindowsのキーボード入力へ変換するデスクトップツールです。

ゲームプロセスやメモリの読み書きは行わず、Windowsの通常のキー入力APIを使用します。

> [!IMPORTANT]
> **本ツールは必ず「管理者として実行」してください。**<br>
> `ResonanceMidiPlayer.exe`を右クリックし、「管理者として実行」を選択します。管理者権限がない場合、ゲームへキー入力が届かず演奏できないことがあります。

> [!WARNING]
> **第三者の著作権その他の権利を侵害する演奏には使用しないでください。**<br>
> 利用者は、ゲーム内に表示される楽器演奏機能の確認事項へ承諾済みであり、自作曲、権利者から許諾を得た曲、または利用条件上演奏可能な曲だけを使用するものとします。権利侵害や利用規約違反にあたる演奏は、アカウント停止（BAN）などの措置を受ける可能性があります。
>
> 本ツールは一般的なMIDI入力補助ツールであり、著作権侵害や利用規約違反を推奨・助長する目的で制作・配布しているものではありません。使用するMIDIと演奏内容の確認は利用者自身の責任で行ってください。

## スマートアレンジ（目玉機能）

音域が広くてそのままではゲームで弾きにくい曲を、**曲の雰囲気をできるだけ保ったまま、自動でゲーム向けに調整**する機能です。低音の迫力を残す「ベース」、低音と高音メロディーを両立する「ワイド」、最も安定して崩れにくい「メロディ」から、曲ごとに選べます（OFFで原曲のまま）。

さらに**再生速度にも連動**し、**速度を落とすほど原曲に忠実**な演奏へ、上げるほど簡略化した演奏へと自動で変わります。原曲をなるべく再現したいときは速度を少し落とすのが有効です。

使い方・各モードの詳しい説明は、下記「[スマートアレンジ（ベータ）](#スマートアレンジベータ)」を参照してください。

## v0.3.2の既知の制限

**スマートアレンジはベータ版**です。方針（ベース／ワイド／メロディ）に応じて低音や主旋律らしい声部を保護し、ほかの音をオクターブ単位で整理したり、広い和音を削ったりして音域切替を減らします。MIDIの作りによっては主旋律を正しく推定できず、意図と異なる調整になる場合があります（そのときは「ベース」または「OFF」を選んでください）。スマートアレンジは再生速度に連動し、速度を下げるほど原曲に近い形、上げるほど簡略化した形になります。新しく読み込んだ曲はOFFで、メイン画面やプレイリストから曲ごとにモードを選べます。整理の効果が薄い曲は、モードをオンにしていても原曲のまま再生します。

**スマートアレンジがOFFのときは崩れやすい**です。原曲どおりに鳴らすぶん、ゲームのオクターブ切替に頼りきりになります。特に低音から高音へ一気に飛ぶ箇所や、切替が短時間に集中する箇所では、切替が間に合わず**演奏が崩壊**することがあります。こうした曲では「メロディ／ワイド／ベース」を選ぶか、再生速度を少し落とすと崩れにくくなります。

**音域補正はベータ版**です。演奏できる音域の外にある音をオクターブ単位で移動して鳴らす機能ですが、原曲どおりの音の高さにはなりません。演奏できる音域が狭い状態では移動が頻繁に発生し、原曲の印象が変わる場合があります。

ピアノに加えて**ギター・ベース・ドラムへベータ対応**しています。ただし、各楽器の鍵盤切替規則がピアノと完全に同じかは十分に実機検証できていません。ギター／ベースのハーモニクス、ミュート、オーバードライブなど、音域以外の特殊奏法には未対応です。ドラムはGeneral MIDIの多数の打楽器をゲーム内の9音へ集約するため、原曲とは異なる音になる場合があります。

作者がゲーム内の音域解放に必要な実績をまだ達成していないため、ピアノで実際に発音させて確認できている音域は**C3～B6の4オクターブ**です。ツールはA0～C8まで扱えますが、それより低い音・高い音は実機未検証です。

音域切替はゲームへ`L Shift`・`L Ctrl`・`>`・`<`のキー入力を送って行います。短時間に音域切替が集中する曲や、ゲーム側の処理負荷が高い状況では、切替入力が認識されず、**ツールが想定する音域とゲーム画面の鍵盤位置がずれる**場合があります。その場合は演奏を停止し、ゲーム側の鍵盤を`Z = C3`の初期位置へ戻してから再生してください。

**音が抜ける問題は改善を続けています**。v0.3.2では、音域を切り替えた前後で**同じキーを別の音に使い回す場面**で音が鳴らないことがある問題を修正しました。それでも抜ける箇所がある場合は、Xの告知投稿へご報告ください。

**更新の確認はインターネット通信を行います**。起動時にGitHubの最新リリースを確認し、新しい版があるときだけ通知します（オプションでオフにできます）。通信に失敗した場合は何も表示しません。

## 主な機能

- SMF format 0 / 1の`.mid`・`.midi`ファイルを読み込み
- MIDIトラックを複数選択して、必要なパートだけを通常再生
- 再生・停止・先頭へ戻る・シーク
- 再生速度、移調、キー保持時間、開始カウントダウンの設定
- ピアノ／ギター／ベース／ドラムの選択（ピアノ以外はベータ）
- General MIDI channel 10をゲーム内の9種類のドラム音へ割り当て
- MIDI channel 10のドラム除外（メロディ楽器選択時）
- 再生前のサステイン状態チェック（初期値オン）
- A0～C8のピアノ音域に対応
- 譜面全体を先読みし、`L Shift`・`L Ctrl`・`>` / `<`の有効条件を追跡する音域表示の自動切り替え
- 曲をゲーム向けに自動調整するスマートアレンジ（ベータ・ベース／ワイド／メロディの3モード、再生速度に連動）
- 音域の解放段階の設定と、演奏できない音をオクターブ単位で音域内へ移動する音域補正（ベータ）
- 曲のライブラリ（プレイリスト、最近弾いた曲、お気に入り）
- 曲ごとのスマートアレンジモードをプレイリストへ表示・保存
- プレイリストの連続再生、シャッフル、1曲／全曲リピート、曲間カウントダウン
- MIDIデータから生成する軽量な疑似スペクトラム表示
- OPTIONSから疑似スペクトラムを非表示にする設定
- ゲーム以外へフォーカスが移った場合の安全停止
- 対象ゲームウィンドウの自動再取得とフォーカス
- 常に手前、背景透明度、UIサイズ（0.5～2.0倍）、ウィンドウ位置の保存

## ダウンロード

GitHubのReleasesから最新版のZIPをダウンロードし、展開後に`ResonanceMidiPlayer.exe`を実行してください。

デジタル署名のない個人制作アプリのため、Windows SmartScreenが警告を表示する場合があります。

## 基本的な使い方

1. `ResonanceMidiPlayer.exe`を右クリックし、「管理者として実行」を選択します。
2. ゲームで使用する楽器の演奏画面を開きます。
3. `+ MIDI`から演奏するMIDIファイルを選択します。
4. 対象欄で「ブループロトコル：スターレゾナンス」を選択します。
5. 必要に応じてレイヤーアイコンから再生するMIDIトラックを選択します。
6. 必要に応じて音符アイコンから楽器と音域の解放段階を選択します。
7. 再生ボタンを押します。

ピアノ／ギター／ドラムの鍵盤初期位置は`Z = C3`、ベースは左側の初期位置を前提としています。再生前に譜面全体を解析し、低音・初期・高音の3つのベース位置と、`L Ctrl`・補正なし・`L Shift`の状態を別々に追跡して、ゲーム側で無効になる操作を避けた切替経路を先に決定します。同時刻の音が1つの3オクターブ表示に収まらない場合は、7つの表示状態から必要な音を覆える組み合わせと巡回順を求めます。完全な同時発音はできないため最低音を先に鳴らし、その条件の中で次の音へつながる切替回数を抑えます。シーク後は開始カウントダウン中に、次の打鍵に必要な最初の表示位置へ準備します。

初期設定は次のとおりです。

- 再生速度：1.0
- 移調：0半音
- キー保持：1ms（現在のメロディ楽器は音符本来の長さを優先）
- 音域切替待機：20ms
- ドラム除外：オン
- 音域表示の自動切替：常時オン
- 開始カウントダウン：3秒
- サステイン状態のチェック：オン
- 起動時に更新を確認：オン
- 常に手前：オン
- 背景透明度：50%
- UIの大きさ：1.0倍
- 音域補正：オフ
- スマートアレンジ：OFF（曲ごとに記憶）
- 音域の解放段階：実績③解放後（A0～C8）

設定は`%APPDATA%\ResonanceMidiPlayer\config.json`に保存されます。リポジトリや配布ZIPにユーザー設定は含まれません。

## 曲のライブラリ

ヘッダーのリストアイコンから、次の3つの表示を切り替えられます。

- **プレイリスト**：再生順をドラッグして並べ替え、連続再生できます。
- **最近弾いた曲**：実際に再生が始まった曲を新しい順に最大50曲表示します。MIDIを読み込んだだけでは履歴に追加されません。
- **お気に入り**：右クリックから登録した曲をまとめて表示します。

トランスポート（シャッフル・前後・リピートが並ぶ場所）の**★ボタン**をオンにすると、連続再生の対象が**お気に入りだけ**になります（曲名順）。オフのときはプレイリストが対象です。★オン中は、前の曲／次の曲・リピート・シャッフルもお気に入りの中だけで動き、お気に入りの曲をダブルクリックすればそこから連続再生します。

一覧の「調整」列には、その曲へ保存したスマートアレンジモードが表示されます。列をクリックすると、`OFF → メロディ → ワイド → ベース`の順に切り替わります。右クリックの「スマートアレンジ」から直接選ぶこともできます。

曲の識別にはMIDIデータの内容を使用します。同じMIDIを改名して読み直しても履歴やお気に入りを引き継ぎます。ファイルを移動して見つからなくなった場合は行が薄く表示され、右クリックの「ファイルを探して再リンク」から同じ内容のMIDIだけを再登録できます。

## 音域補正（ベータ）

ゲーム内の実績で解放していない音域は、鍵盤が灰色で表示され音が鳴りません。解放が進んでいない状態では、低音や高音を含む曲を読み込んでも該当する音が抜け落ちます。

音域補正を有効にすると、演奏できない音をオクターブ単位で移動させ、鳴らせる範囲へ収めます。音符ごとに個別に折り返すとメロディの起伏が崩れるため、**フレーズ単位でまとめて移動**します。和音は分解せず、同時に鳴る音はまとめて同じ量だけ移動します。

ヘッダーの音符アイコンのボタンから設定を開きます。

1. 「音域外の音をオクターブ単位で音域内へ補正する」にチェックを入れます。
2. 「音域の解放段階」を、自分がゲーム内で解放している状況に合わせて選びます。

| 解放段階 | 演奏できる音域 |
| --- | --- |
| 初期状態 | C3～B4 |
| 実績①解放後 | C3～B6 |
| 実績②解放後 | A0～B6 |
| 実績③解放後 | A0～C8 |

チェックを入れていない場合、音域外の音はこれまでと同じく鳴りません。設定した解放段階は演奏そのものにも反映され、鳴らない音のために鍵盤が動くことはありません。

原曲どおりの音の高さにはならないため、演奏できる音域が狭い状態では原曲の印象が変わる場合があります。

## スマートアレンジ（ベータ）

ゲームの鍵盤は一度に3オクターブしか表示できず、離れた音域を弾くにはオクターブ切替が必要で時間がかかります。そのため、低音から高音まで広く使うMIDIをそのまま流すと、音域切替が間に合わずに崩れたり、和音が分解されたりします。**スマートアレンジは、原曲の雰囲気をできるだけ保ったまま、曲をゲームで弾ける形へ自動調整する機能**です。音符そのものの高さ・時刻・リズムは基本的に変えず、フレーズ単位でのオクターブ移動と、弾ききれない和音の整理だけを行います。設定はMIDIごとに記憶されます。

メイン画面の音域グリフ・ボタンで、曲ごとにモードを選びます。ボタンを押すたびに `OFF → メロディ → ワイド → ベース` の順で切り替わり、ボタンのグリフ（3本バー）が強調している音域を表します（プレイリスト一覧の「調整」列からも切り替えられます）。

**選び方の目安**：まずは **メロディ**（最も安定）。低音のリフやベースラインが曲の要なら **ベース**。低音の迫力と高音の華やかさを両方できるだけ残したいなら **ワイド**。うまくいかない曲や、原曲そのままがよい曲は **OFF**。

**再生速度との連動**：スマートアレンジは**再生速度に応じて整理の強さを変えます**。速度を下げると音域切替に余裕ができるため、より原曲に近い形（あまり畳まない）で演奏し、速度を上げると切替が間に合わないぶん、より簡略化した形で演奏します。**原曲をなるべく忠実に再現したいときは、速度を少し落とす**のが有効です。

| モード | 動作 |
| --- | --- |
| OFF | 音程を変更せず、原曲を優先します |
| メロディ | 主旋律らしい上声を守り、広い和音を最大4音へ整理して音域切替を積極的に減らします。**最も崩れにくいモード**です。分割和音は最高音から鳴らします |
| ワイド | 低音と高音メロディーの**両方を原オクターブのまま保持**し、どちらも移調しません。代わりに同時に鳴る和音を**二声（低音＋高音メロディー）だけに削って密度を下げ**、残った低音と高音を音域表示の反復切替（横跳び）とキー保持で鳴らします。全音域を残す代わりに中間の和音の厚みは薄くなります（二声寄りの曲に向き、和声の厚い曲では痩せて聞こえます）。分割和音は音価の長い方をずらし、短い方を定刻に鳴らします |
| ベース | 低音フレーズを原音程で守り、必要なら高音メロディーを下げて高音部への切替を減らします。低音の迫力を優先します。分割和音は最低音から鳴らします |

**OFFのときの注意**：OFFは原曲どおりに鳴らしますが、その分ゲームのオクターブ切替に頼りきりになります。特に**低音から高音へ一気に飛ぶ箇所や、切替が短時間に集中する箇所**では、疑似キー入力による音域切替が間に合わず、切替の取りこぼし（音域シフトミス）で演奏が崩壊することがあります。こうした曲では **メロディ／ワイド／ベース** のいずれかを選ぶと切替回数が減り、崩れにくくなります。

スマートアレンジでは音符の時刻・長さ・リズムを変更せず、フレーズ単位・オクターブ単位で音域を移動します。「ベース」では低音フレーズを固定して高音側を下げ、「メロディ」では主旋律らしい上声を固定して伴奏側を整理します。時間差で鳴るアルペジオは削らず、同時発音によって分割演奏が必要になる広い和音か、上限を超える過密和音だけを整理します。最低音・メロディー・3度・7度などを優先し、オクターブ重複や内声の5度から省略します。

変更前後の譜面から音域切替の負荷を推定し、十分な改善が見込めない場合は、ボタンがオンでも原曲をそのまま使用します。適用された場合はMIDI情報欄に調整した音数を表示し、ボタンへマウスを重ねると保護したメロディ音数と推定負荷の減少量を確認できます。

主旋律の判定はMIDIトラックを利用者に選ばせず自動で行います。そのため、1トラックへメロディと伴奏が複雑に混在するMIDIや、低音が主旋律の曲などでは意図と異なる場合があります。その場合は「ベース」またはOFFを選んでください。選択はMIDI内容のSHA-256へ紐付けて記憶され、改名しても引き継がれます。元のMIDIファイル自体は変更しません。

## 更新の確認

起動時にGitHubの最新リリースを確認し、新しいバージョンがある場合だけ画面上部に通知バーを表示します（通信に失敗しても何も表示せず、エラーも出しません）。バーの「詳細」から変更点を確認し、「ダウンロードを開く」でリリースページを開けます。確認は1時間に1回までで、オプションの「起動時に更新を確認する」でオフにもできます。「更新を確認」ボタンからはいつでも手動確認できます。現在のバージョンはメイン画面の「RESONANCE MIDI」の右に表示されます。

原曲のままでも音域切替の負荷が十分低いと判定した曲は、ONのモードを選んでいても音程を変更しません。広い音域を自然に往復するアルペジオなどを、わずかな切替削減のために折り畳まないための保護です。
